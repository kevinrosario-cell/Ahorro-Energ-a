❓ ¿Cómo encontrar la potencia de mi equipo?
  1. Etiqueta trasera: La mayoría de equipos tienen una etiqueta con especificaciones técnicas donde aparece "W" (vatios).
  2. Manual del equipo: Consulta las especificaciones técnicas en el manual original o en línea.
  3. Sitio web del fabricante: Busca el modelo exacto en la página del fabricante.
  4. Medidor de consumo: Usa un medidor de vatios (generalmente puedes comprar uno o rentarlo) para medir el consumo real.
